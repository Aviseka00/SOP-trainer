# Changelog

## 0.7.0 — 18 October 2026

- Fixed provider TLS using the native certificate store while retaining hostname and certificate verification. Synthesia and Kling read-access checks now succeed.
- Ran a real eight-scene fictional scientist cloud test from the bundled sample SOP PDF through summary, contextual animations, original cloud audio and final 720p/30fps composition.
- Added narration-bound cloud-video import for chat-connector/provider website renders. Changed narration or file checksums invalidate the imported match.
- Measured zero compositor-added audio offset at 2 ms measurement resolution across all eight scenes. Original neural phoneme/viseme accuracy is not certified by this measurement.
- Added sampled landmark/contact-sheet evidence for face, eye and hand activity, plus a distinct hand-wetting visual template.
- Kling generation returned HTTP 429 and its resource API reported zero active packages; local schematics were used explicitly. No repeated paid requests were made.

## 0.6.0 — 18 October 2026

- Added AI providers setup for HeyGen, Synthesia and Kling developer keys, optional current-user Windows DPAPI storage, read-only access checks and a forget-keys action. No plaintext credential fallback is used.
- Added Synthesia v2 presenter generation with private visibility, explicit test/production mode, preserved speech text and original provider audio in composition.
- Added Kling official text-to-video generation for selected/all scene contexts with model/duration controls, explicit credit authorization and draft media review.
- Added cloud task journals and recovery that do not resubmit unknown paid outcomes. Provider media downloads are bounded and limited to supported hosts.
- Local animations and local presenter options remain available. Neither Synthesia nor Kling has been live credential-tested in this app.

## 0.5.0 — 18 October 2026

- Added a source-linked summary, key-point and speech editor before storyboard generation. Extractive selection retains critical/prohibited and numeric instruction sentences even when they exceed the target length.
- Added optional local Ollama speech rewriting with retained point IDs, omission checks and numeric/prohibition checks; edits still require human source comparison.
- Added summary-derived scene creation and automatic contextual schematic animation jobs, stale-source protection and draft downloads.
- Added an optional HeyGen v3 Avatar IV adapter and fictional scientist configuration. Provider video and its own speech are composed together; local TTS never replaces cloud speech.
- API keys stay in session memory/worker environments, outside saved project and job JSON. Paid submissions are journaled; unknown outcomes are not automatically resubmitted.
- Live app-to-HeyGen generation requires a user API key and has not been tested with credentials. Chat-created samples do not establish API integration performance.

## 0.4.0 — 18 October 2026

- Added selectable fictional Lab scientist and Lab technician portraits, with preserved original educator, exact generation prompts and verified selection/save behavior.
- Inspected the supplied presenter reference and added an original fictional portrait created with the built-in image generation tool.
- Integrated real SadTalker audio-driven facial/head animation through an isolated Python 3.10 CPU environment; no static-image substitute is used when inference fails.
- Added Presenter studio, explicit likeness permission, actual speaking auditions, expression/pose controls, model readiness checks, measured performance display, caching and per-scene integration with the original TTS waveform.
- Added circular picture-in-picture and end-frame holds so a generated presenter does not restart its mouth motion at a rounding boundary.
- Added explicit source/model setup scripts, download/source hashes, separate dependency lock, optional installer and runtime verification.
- Actual CPU benchmark: 55 frames / 2.2 seconds produced in 764.72 seconds. Full-body gestures and GTX 1050 acceleration remain untested/unimplemented; CPU speed is impractical for long videos.
- Added real cached-presenter composition acceptance testing alongside foundation, visual and UI regression tests.
