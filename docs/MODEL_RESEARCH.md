# Model and repository review

Reviewed official project pages during implementation on 17 October 2026. This is a selection screen, not a compatibility certification. No third-party avatar weights were downloaded and no avatar quality benchmark was performed. Storage figures for a complete stack are unknown unless explicitly stated; do not assume the main checkpoint is the entire download.

| Component | Official source and licensing information | Decision for this release |
| --- | --- | --- |
| MuseTalk | [Official repository](https://github.com/TMElyralab/MuseTalk), [official weights](https://huggingface.co/TMElyralab/MuseTalk). README identifies MIT code, commercially usable trained model and separate dependency licenses. Installation specifies Python 3.10, PyTorch 2.0.1 and CUDA/MMLab components. | Candidate for a separate isolated environment. The published 4 GB result concerns an RTX 3050 Ti, not a GTX 1050. Pascal compatibility, memory use and quality are unverified here. Face inpainting does not provide body gestures. |
| LivePortrait | [Official repository, redirected from KwaiVGI](https://github.com/KlingAIResearch/LivePortrait). MIT project; third-party face detection weights require separate license review. | Driving-video portrait animation is not a complete audio-to-lip pipeline. Not selected as the primary speech renderer. No target-PC test. |
| SadTalker | [Official repository](https://github.com/OpenTalker/SadTalker). README states Apache 2.0 and removal of its previous noncommercial restriction. Published setup uses an older separate Python/PyTorch environment; dependencies and weights still need review. | Portrait-plus-audio candidate for later isolated testing. No claim of natural hands or full-body motion. Not installed. |
| Wav2Lip | [Official repository](https://github.com/Rudrabha/Wav2Lip), [maintainer explanation](https://github.com/Rudrabha/Wav2Lip/issues/104). Public pretrained release restricts commercial use. | Excluded from the default organizational training stack. No weights downloaded. |
| Piper | [Maintained OHF repository](https://github.com/OHF-Voice/piper1-gpl). GPL-3.0 engine; individual voice model cards have their own terms. | CPU neural speech candidate. Distribution obligations and each voice license must be reviewed before bundling. No English/Hindi/Odia model is claimed installed. |
| Kokoro | [Official Kokoro-82M model card](https://huggingface.co/hexgrad/Kokoro-82M). Apache-2.0 model with an 82-million-parameter architecture. | Promising optional local speech candidate. Language inventory, pronunciation quality, Windows phonemizer setup and measured performance still need a working installation test. No language support claimed by this app from Kokoro. |
| XTTS-v2 | [Official Coqui model card](https://huggingface.co/coqui/XTTS-v2). Weights use the Coqui Public Model License. | Not bundled as a universally permissive organizational voice/cloning solution. No cloning implementation or consent records exist in this release. |
| Ollama | [Official API](https://docs.ollama.com/api/generate). Structured JSON/schema output supported. Runtime and individual model terms are separate. | Optional loopback adapter implemented. User installs runtime and chooses a licensed model separately. No automatic pull or cloud access. Adapter tests use invalid/missing-service cases; live-model inference not benchmarked. |
| Edge TTS | [Official package repository](https://github.com/rany2/edge-tts). Online Microsoft speech service adapter. Package licensing does not establish service availability or usage rights. | Existing optional online path retained, with live voice discovery, timeouts and word-boundary ingestion. Network synthesis was not verified in this environment. Windows SAPI is the tested offline fallback. |

Repository pages contain upstream examples, not evidence of output quality on this PC. Recent maintenance, exact commits, all transitive weight terms and CUDA builds must be rechecked when an advanced engine is actually installed. No benchmark or visual-quality number from another machine is reported as a measurement of the GTX 1050.

No mandatory subscriptions, credit cards, paid APIs or cloud GPU services are used. Optional advanced models need disk estimates and explicit download authorization in the future model manager; the current manager only inspects installed capabilities.
